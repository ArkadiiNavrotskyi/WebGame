# Наше небо ✦

Пять игр для двоих в браузере. Соединение идёт напрямую между устройствами (WebRTC/PeerJS), без своего сервера.

| Игра | Что внутри | Роли |
|---|---|---|
| ✨ Созвездие | 4 режима (Угадайка, Длинная партия, Блиц, Рисуем вместе), 3 кисти, альбом неба | по очереди / вместе |
| 🌊 Маяк | кампания из 5 ночей (льдины, водовороты, щупальца, туман), 7 улучшений, Вечный шторм | Капитан (ПК) / Смотритель (телефон) |
| 🗝️ Два ключа | 4 главы, 14 комнат: плиты, созвездия, кольца, колокола, мосты, подъёмники, тьма + финал | Путник (ПК) / Хранитель (телефон) |
| 🌙 Сад под звёздами | 10 уровней острова, задания, 7 растений, 7 зверьков, падающие звёзды, сохраняется | вместе |
| 🃏 Хроники | 3 фракции (Солнце, Луна, Лес), силы героев, ~40 карт | друг против друга |

## Как проверить у себя

1. Двойной клик по `запустить.bat` (нужен Node.js), откроется http://localhost:8080
2. Нажми «тест в двух вкладках», создай комнату, во второй вкладке войди по коду.

## Что можно поменять

`js/config.js`:
- `finalMessage` — послание в финале «Двух ключей»
- `customWords` — ваши слова для «Созвездия»
- `siteTitle` — название сайта

## Структура

- `index.html`, `css/style.css` — оболочка
- `js/net.js` — соединение (PeerJS + тестовый режим `?local=1`)
- `js/app.js` — стартовый экран, хаб с островами, выбор ролей
- `js/fx.js` — частицы, свечение, символы, звук, сенсорное управление
- `js/games/*.js` — по файлу на игру
